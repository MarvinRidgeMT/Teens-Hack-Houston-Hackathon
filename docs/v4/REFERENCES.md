# V4 reference analysis (lane R)

Internal study only. Captured 2026-11-21 with `test/dev/web-shots.mjs` (headless Chrome for Testing, SwiftShader GL),
plus the served HTML/JS bundles and a rendered-DOM dump. **Headless stills cannot show motion.** Anything about motion
below is marked *(markup)* = inferred from library names, config objects, data attributes or class names in the code,
not watched. Nothing here was seen animating.

Reachability: all six loaded. Caveats: buckssauce.com and getfactura.app return a Vercel bot checkpoint (HTTP 429) to
plain `curl`, but render in headless Chrome. theinfinitycastle.site renders only its entry gate ("Enter the castle"); the
3D scene sits behind that click and was not captured; the 375 px shot is black apart from the footer. dominoai.up.railway.app
is a Vite SPA (empty `#root` in HTML) that renders fully in Chrome. Full-page stitches of A, B, C, F show the hero repeated or
long blank runs: those are pinned/fixed layers, not real page content.

## Synthesis for PickUp: "Soft Liquid Future"

1. One pinned stage, five beats (Working → Interrupted → Park → Return → Resume), driven by native scroll mapped to a damped 0–1 progress with scrub of about 0.8 (C, E), plus a sticky 5-step stepper and a right-edge tick pager (B, C).
2. The 3D laptop is the only hero object (A) and shows the **real extension as live DOM**, not a screenshot (F, B), with one honesty footnote that the demo is a recorded replay (B).
3. Glass stays believable: blur 8–14 px, slight saturation, a mint/blush two-temperature rim light (F), a faint procedural grain on the pearl canvas (B); no fog, no bloom by default.
4. Type does the personality: one outlined-plus-solid emphasis line (A), numbered mono kickers and one-word beat titles (E, B), split-text only on beat titles; deep plum on lavender always meets contrast, never dim grey at rest.
5. Engineering discipline from D: one `MOTION` and one `QUALITY` config, DPR ≤ 2, a low tier without post-processing, a reduced-motion scale with static frames per beat, WebGL2 first, and no wheel hijacking or entry gate.
